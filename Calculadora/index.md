# Calculadora Mejorada

Aplicación de consola en **C# (.NET 8)** que permite realizar operaciones matemáticas básicas y científicas, con historial de operaciones y calculadora de precios con IVA y descuentos.

## Características

- **Operaciones básicas:** Suma, Resta, Multiplicación, División
- **Operaciones científicas:** Potencia, Raíz Cuadrada, Factorial
- **Calculadora de precios:** Aplica IVA personalizado y descuentos por socio o volumen
- **Historial:** Guarda las últimas 5 operaciones realizadas
- **Gestión de errores:** Manejo de excepciones para entradas inválidas

## Estructura del proyecto

| Clase | Descripción |
|-------|-------------|
| `Calculadora` | Contiene toda la lógica matemática de las operaciones |
| `Program` | Gestiona la interfaz de consola y el flujo del programa |
